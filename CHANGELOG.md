# Changelog

## 1.0.0 (2026-11-10): first public release

One APK for Android 11 and newer (phones and tablets; ARM 64-bit, ARM 32-bit and x86_64):

- **Home screen**: big tiles for Music, YouTube, Video, Network Library and Browser; clock; weather where you are; long-press a tile to choose its app.
- **Player Pure** (built in): music library from the device and USB drives; FLAC, ALAC, WAV, AIFF, DSD (DSF/DFF), CUE sheets, MP3, AAC, Ogg, Opus;
  its own USB Audio driver for **bit-perfect** playback on USB DACs (native DSD or DoP when the DAC supports it); a big DAC screen.
- **Web remote**: control the device from any phone or computer browser on the same Wi-Fi. PIN-protected (made up at random on each device, changeable),
  QR code sign-in, music, volume, apps, mouse and keyboard, files, and YouTube search with your own free API key.
- **Screen saver**: clock, weather and the music that is playing, while charging.
- **Set up checklist** on first start: every permission explained, one tap each.
- **11 languages**: English, Tiếng Việt, Español, 中文（简体）, हिन्दी, Français, Deutsch, 日本語, 한국어, Português (Brasil), Русский
  (translations made with AI help; corrections welcome).

Based on the author's private "Media Home" and "Player Pure" apps for a Samsung Galaxy Tab S7 FE media setup.
